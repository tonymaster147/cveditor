Drop client/employer logos in this folder.

Expected files (referenced from Gallery.jsx):
  nhs.svg          (or .png)
  pwc.svg
  astrazeneca.svg
  deloitte.svg
  amazon.svg

Format: SVG preferred (scales to any size, smallest file). PNG with transparent
background is fine. Aim for ~200px wide, monochrome or original colour. The
Gallery renders them at ~96px wide, grayscale by default with full colour on hover.

To add or remove logos, edit the LOGOS array in Gallery.jsx.
